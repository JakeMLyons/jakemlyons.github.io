# jakemlyons.github.io

The landing page served at <https://jakemlyons.github.io/>.

Self-contained pages with inline styles: `index.html`, the landing page, and
`privacy/index.html`, the privacy policy at `/privacy/` that Google requires
before a personal OAuth app can be published. There is no build step and no
dependencies. Edit a file, push to `main`, and GitHub Pages rebuilds it.

The repo name is fixed: GitHub only serves a user site from a repository
named `<username>.github.io`. Every other repo dropped its prefix and moved
into a category directory; this one could not, so it is the one that stays
at the top level.

This site previously hosted the Campaign Engine. That moved out in August
2026, to a repo of its own, which is the source of truth for it.
