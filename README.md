# jakemlyons.github.io

The landing page served at <https://jakemlyons.github.io/>.

One self-contained `index.html` — styles are inline, there is no build step
and no dependencies. Edit the file, push to `main`, and GitHub Pages rebuilds
it.

The repo name is fixed: GitHub only serves a user site from a repository
named `<username>.github.io`, so this one cannot be renamed to match the
`Category_Name` convention the other repos use.

This site previously hosted the Campaign Engine. That moved out in August
2026 — it lives in `RPG_TextAdventure`, which is the source of truth for it.
